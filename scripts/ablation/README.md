# Ablation / Control Scripts

These scripts reproduce the manuscript control experiments without including
private clinical notes, generated results, ground-truth labels, or FAISS index
files.

The public scripts keep the original control logic but replace local hard-coded
paths with command-line arguments.

## Control 1: No Guideline

Runs the no-guideline single-step Phase 1 extraction from the original
`baseline1_no_guideline.py`, then uses the curated KCD FAISS index for Phase 2
and the shared rule corrector for Phase 3.

```bash
python scripts/ablation/run_control1_no_guideline.py \
  --input-dir data/private_ed_notes \
  --model-id qwen.qwen3-32b-v1:0 \
  --faiss-index /path/to/curated_kcd_faiss_index \
  --rules-csv rules/code_correction_rules.csv \
  --phase1-output outputs/control1/phase1_no_guideline.json \
  --phase2-output outputs/control1/phase2_result.json \
  --phase3-output outputs/control1/phase3_result.json \
  --rule-log outputs/control1/phase3_applied_rules.csv \
  --batch-size 50 \
  --batch-dir outputs/control1/baseline_results
```

## Control 2: Original KCD Descriptions

Starts from the standard CLEVER guided Phase 1 output and runs Phase 2 with the
original KCD FAISS index instead of the curated KCD FAISS index. Phase 3 uses
the shared rule corrector.

```bash
python scripts/ablation/run_control2_original_kcd_descriptions.py \
  --phase1-output outputs/phase1_output.json \
  --faiss-index /path/to/original_kcd_faiss_index \
  --rules-csv rules/code_correction_rules.csv \
  --phase2-output outputs/control2/phase2_result.json \
  --phase3-output outputs/control2/phase3_result.json \
  --rule-log outputs/control2/phase3_applied_rules.csv
```

## Control 3: No Guideline + Original KCD Descriptions

Starts from the no-guideline Phase 1 output generated by Control 1 and runs
Phase 2 with the original KCD FAISS index. Phase 3 uses the shared rule
corrector.

```bash
python scripts/ablation/run_control3_no_guideline_original_kcd.py \
  --phase1-output outputs/control1/phase1_no_guideline.json \
  --faiss-index /path/to/original_kcd_faiss_index \
  --rules-csv rules/code_correction_rules.csv \
  --phase2-output outputs/control3/phase2_result.json \
  --phase3-output outputs/control3/phase3_result.json \
  --rule-log outputs/control3/phase3_applied_rules.csv
```

## Evaluation

Use the same cumulative evaluation scripts as the main CLEVER pipeline:

```bash
python scripts/evaluate_pipeline_phase2.py \
  --ground-truth data/private_ground_truth.json \
  --phase2-output outputs/control1/phase2_result.json \
  --output-excel outputs/control1/phase2_evaluation.xlsx

python scripts/evaluate_pipeline_phase3.py \
  --ground-truth data/private_ground_truth.json \
  --phase3-output outputs/control1/phase3_result.json \
  --output-excel outputs/control1/phase3_evaluation.xlsx
```

Repeat the same evaluation commands for `control2` and `control3` by changing
the output paths.



## Ablation Statistics

After generating the Phase 3 evaluation workbooks for CLEVER and all controls,
run the paired statistical comparison used in the manuscript ablation table:

```bash
python scripts/ablation/evaluate_control_statistics.py \
  --clever-eval outputs/clever/phase3_evaluation.xlsx \
  --control1-eval outputs/control1/phase3_evaluation.xlsx \
  --control2-eval outputs/control2/phase3_evaluation.xlsx \
  --control3-eval outputs/control3/phase3_evaluation.xlsx \
  --output-excel outputs/ablation_statistics.xlsx
```

The script reports paired t-test results used in the manuscript ablation table.
