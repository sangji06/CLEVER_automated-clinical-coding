# Data Availability

This repository does not include patient-level emergency department notes,
ground-truth annotations, model outputs derived from patient records, the
curated KCD database, or FAISS indexes derived from the curated database.

The original KCD reference files should be obtained from the official source
according to the applicable terms of use. The curated KCD database used in the
study is not distributed here because it incorporates institutional terminology
resources and clinical assets.

All examples included in this repository are synthetic and do not correspond to
real patient records.
