# Public File Classification

| Category | Public Status | Repository Handling |
|---|---:|---|
| Phase 1/2/3 source code | Public after sanitization | Included under `src/clever/` and `scripts/` |
| Synthetic examples | Public | Included under `examples/` |
| Code correction rules | Public | Included under `rules/` |
| Annotation tool source code | Public after sanitization | Included under `tools/annotation_app/`; exclude clinical notes and generated annotation outputs |
| Clinical notes | Not public | Excluded |
| Ground-truth annotations | Not public | Excluded |
| Patient-derived model outputs | Not public | Excluded |
| Curated KCD database | Not public | Excluded |
| FAISS indexes derived from curated KCD | Not public | Excluded |
| Embedding model comparison experiments not used in the manuscript | Not public release scope | Excluded |
| Ablation source scripts | Public after sanitization | Include under `scripts/ablation/`; exclude generated results and patient-derived examples |
| Manuscript and thesis files | Not public release scope | Excluded |
